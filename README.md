## Как это работает
 
- Доска - это вложенный список (список списков), клетки хранят числовые коды: `0`/`1` — пустые светлая/тёмная клетки, `4`/`5` — шашки игроков.
- Каждый игрок описан словарём с именем, цветом шашек, разрешённым направлением хода и счётом взятых шашек.
- Ход вводится двумя координатами — "откуда" и "куда" (например `01` → `04`).
- Вся логика проверки и применения хода собрана в одной функции, которая возвращает `True`/`False` — удался ли ход.
